# Aula1205
# Loja de Carros

Projeto desenvolvido em PHP utilizando PostgreSQL.

## Funcionalidades

- Cadastro de veículos
- Cadastro de clientes
- Listagem de veículos
- Listagem de clientes

## Tecnologias

- PHP
- PostgreSQL
- HTML
- CSS
- XAMPP

## Como executar

1. Coloque a pasta no htdocs do XAMPP
2. Inicie o Apache
3. Crie o banco Aula1205 no PostgreSQL
4. Execute o arquivo creates.sql
5. Acesse:

http://localhost/Aula1205/public/index.php
